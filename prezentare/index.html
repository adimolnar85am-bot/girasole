02 / Panou de administrare

Cum actualizezi site-ul

Admin este zona in care editezi textele, fotografiile, meniul si datele de contact. Modificarile nu se salveaza automat. Le verifici si apoi apesi butonul de salvare.

Acces protejat

Panou de administrare Girasole

Ai nevoie de parola transmisa separat de persoana care administreaza proiectul. Dupa autentificare vei vedea meniul lateral cu cele sapte sectiuni explicate mai jos.

01

General

Titlu si descriere SEO

Aceasta zona controleaza titlul paginii si descrierea folosita de motoarele de cautare sau in unele previzualizari de link. Nu modifica textele vizibile din sectiunile site-ului.

  1. Deschide sectiunea General din meniul Admin.
  2. Completeaza titlul paginii cu numele locatiei si tipul activitatii.
  3. Scrie o descriere scurta si clara, care sa includa Girasole, panini, cafea si Bucuresti.
  4. Verifica textul si apasa Salveaza modificarile.
Recomandare: pastreaza titlul concis si descrierea naturala. Evita sa repeti aceleasi cuvinte doar pentru SEO.
02

Cover

Prima zona pe care o vede vizitatorul

Aici schimbi mesajul principal, eticheta butonului catre meniu si fotografiile care ruleaza in partea de sus a site-ului.

  1. Deschide Cover si editeaza textul principal si textul butonului.
  2. Pentru o fotografie noua, apasa Adauga fotografie.
  3. Incarca o imagine de pe calculator sau alege una din biblioteca foto.
  4. Foloseste sagetile sus/jos pentru ordinea imaginilor. Sterge fotografiile pe care nu le mai folosesti.
  5. Apasa Salveaza modificarile si verifica prima zona a site-ului.
Recomandare: alege fotografii de calitate, cu subiect clar si suficient spatiu pentru text. Prima fotografie stabileste impresia initiala.
03

Despre

Povestea si prezentarea locatiei

Sectiunea contine o eticheta scurta, un titlu, un text de prezentare si un slider foto. Fotografiile se pot schimba automat atunci cand exista mai multe.

  1. Editeaza eticheta, titlul si textul. Pastreaza textul usor de citit si concentrat pe experienta Girasole.
  2. In lista fotografiilor, apasa Adauga element pentru o imagine noua.
  3. Incarca fotografia sau selecteaz-o din biblioteca, apoi completeaza descrierea foto.
  4. Reordoneaza imaginile cu sagetile sau sterge-le pe cele vechi.
  5. Salveaza si verifica sliderul pe site.
Recomandare: foloseste imagini coerente ca lumina si stil. Descrierea foto ajuta si la accesibilitate.
04

Galerie foto

Imaginile de atmosfera

Galeria prezinta imagini cu spatiul, cafeaua, panini si detaliile vizuale ale locatiei. Ordinea din Admin este ordinea folosita in galerie.

  1. Deschide Galerie foto.
  2. Adauga un element nou pentru fiecare fotografie.
  3. Alege imaginea din calculator sau din biblioteca foto.
  4. Completeaza descrierea si foloseste sagetile pentru a schimba ordinea.
  5. Sterge imaginile pe care nu vrei sa le mai afisezi si salveaza.
Recomandare: alterneaza cadre de ansamblu cu detalii de produs. Evita fotografiile foarte asemanatoare una dupa alta.
05

Meniu

Produse, preturi si descrieri

Aici actualizezi textele introductive, nota de subsol si produsele din cele doua categorii: Panini si Caffè. Poti lucra direct in lista sau printr-un fisier Excel, CSV ori JSON.

  1. Deschide Meniu. Editeaza titlul si textul introductiv daca este nevoie.
  2. Pentru o modificare rapida, schimba numele, pretul sau descrierea produsului direct in lista.
  3. Foloseste Adauga element pentru un produs nou, sagetile pentru ordine si Sterge pentru eliminare.
  4. Pentru editare in Excel, apasa Descarca Excel in Admin. Acest fisier contine meniul actual, nu un model gol.
  5. Editeaza fisierul, apoi revino in Admin si apasa Importa fisier. Selecteaza Excel, CSV sau JSON.
  6. Verifica produsele si ordinea importata. La final apasa Salveaza modificarile.
Ordinea produselor: in Excel, coloana Pozitie stabileste ordinea. 1 apare primul, 2 al doilea si asa mai departe. In editor poti folosi sagetile sus/jos.
Atentie: un fisier Excel gol sau un JSON lasat cu valorile exemplu nu trebuie importat ca atare. Completeaza produsele reale inainte de import. Importul inlocuieste categoria prezenta in fisier.
06

Contact

Adresa, program, Instagram si harta

Aceasta sectiune afiseaza informatiile practice de care are nevoie un vizitator ca sa gaseasca locatia si sa verifice programul.

  1. Verifica numele locatiei, adresa si orasul.
  2. Actualizeaza programul si nota despre eventualele modificari ale acestuia.
  3. Completeaza handle-ul si linkul corect de Instagram.
  4. Verifica adresa din campul pentru harta. Foloseste adresa completa, nu doar numele strazii.
  5. Salveaza si testeaza harta si linkul Instagram de pe site.
Important: informatiile trebuie sa fie exacte. Inainte de publicare, verifica adresa si programul cu persoana responsabila de locatie.
07

Footer

Zona de inchidere a paginii

Footer-ul contine textul de identificare al locatiei si linkul catre Instagram, afisate la baza site-ului.

  1. Deschide sectiunea Footer.
  2. Actualizeaza textul de identificare daca se schimba denumirea sau mesajul.
  3. Verifica adresa web Instagram si eticheta linkului.
  4. Salveaza si apasa linkul din partea de jos a site-ului pentru verificare.
Recomandare: pastreaza footer-ul simplu. Verifica atent URL-ul Instagram, astfel incat sa duca la profilul oficial.

03 / Fisiere de lucru

Lucreaza cu meniul in Excel sau JSON

Poti descarca un model pentru a construi un meniu nou. Pentru modificarea meniului deja publicat, foloseste exportul Excel sau JSON din sectiunea Meniu a Admin-ului, ca sa pornesti de la produsele existente.

Modele pentru import

Admin accepta fisiere .xlsx, .xls, .csv si .json. Pentru Excel, formatul recomandat are doua foi, Panini si Caffe. Fiecare foaie foloseste coloanele Pozitie, Produs, Pret si Descriere.

Model Excel gol

Doua foi goale, Panini si Caffe, cu antetele corecte. Completeaza randuri cu produse reale inainte sa il importi.

!
Nu importa sabloanele necompletate.

Un import inlocuieste produsele din categoria inclusa in fisier. Daca vrei sa modifici meniul existent, exporta mai intai datele din Admin, editeaza copia si apoi importa fisierul. Daca vrei sa actualizezi doar Panini, include doar categoria Panini. Categoria care lipseste din fisier ramane neschimbata.

1. Descarca

In Admin, deschide Meniu si exporta meniul actual in Excel sau JSON.

2. Editeaza

Pastreaza numele foilor si antetele. Completeaza fiecare produs si pozitia lui.

3. Importa si salveaza

Incarca fisierul, verifica lista rezultata si apasa Salveaza modificarile.
